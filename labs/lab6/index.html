    Описание набора данных:

    В лабораторной работе используется набор данных Titanic с платформы Kaggle. Данные содержат информацию о пассажирах легендарного лайнера «Титаник», потерпевшего крушение в 1912 году. Набор данных включает 891 запись и 12 признаков, описывающих каждого пассажира. Целевой переменной является столбец Survived, указывающий, удалось ли пассажиру выжить.

    Структура данных:
    Признак Тип данных Описание
    PassengerId int64 Уникальный идентификатор пассажира
    Survived int64 Целевая переменная: 0 — погиб, 1 — выжил
    Pclass int64 Класс билета: 1 (первый), 2 (второй), 3 (третий)
    Name object Имя пассажира
    Sex object Пол: male (мужской), female (женский)
    Age float64 Возраст в годах (есть пропуски)
    SibSp int64 Количество братьев/сестёр и супругов на борту
    Parch int64 Количество родителей и детей на борту
    Ticket object Номер билета
    Fare float64 Стоимость билета в долларах
    Cabin object Номер каюты (много пропусков)
    Embarked object Порт посадки: C (Шербур), Q (Куинстаун), S (Саутгемптон)
    Особенности набора данных
    Характеристика Значение
    Количество строк 891
    Количество столбцов 12
    Количество пропусков Age (177), Cabin (687), Embarked (2)
    Доля выживших 38.4% (342 человека)
    Доля погибших 61.6% (549 человек)
    Типы данных int64 (5), float64 (2), object (5)

    Вывод по первичному анализу данных:

    Статистика числовых признаков: - Средний возраст пассажиров — 29.7 лет (медиана 28 лет) - Средняя стоимость билета — 32.2 доллара (медиана 14.5 доллара) - Выживаемость пассажиров — 38.4% (342 человека выжили, 549 погибли) - Большинство пассажиров путешествовало в 3-м классе

    Гистограммы распределения показали: - Age — распределение близко к нормальному с пиком в 20-40 лет - Fare — сильная правосторонняя асимметрия (много дешёвых билетов и дорогие выбросы до 512 долларов) - SibSp и Parch — большинство пассажиров не имели родственников на борту - Pclass — преобладает 3-й класс

    Итог: Данные требуют обработки пропусков в трёх столбцах и устранения выбросов в признаке Fare.

    Вывод по обработке пропусков:

    В ходе обработки пропусков были выполнены следующие действия:

    Столбец Age: - Среднее значение составило 29.70 лет, медиана — 28.00 лет - Для заполнения 177 пропусков выбрана медиана как более устойчивая к выбросам статистика - Пропуски успешно заполнены, создан новый категориальный признак Age_group с 5 возрастными группами (Ребенок, Подросток, Молодой взрослый, Взрослый, Пожилой)

    Столбец Embarked: - Выявлено распределение портов посадки: S (644), C (168), Q (77) - Наиболее часто встречающееся значение (мода) — порт S (Саутгемптон) - 2 пропуска заполнены модой

    Столбец Cabin: - Обнаружено 687 пропусков (77.1% от всех записей) - Ввиду высокого процента пропусков заполнение статистическими методами нецелесообразно - Создан новый признак Cabin_letter на основе первой буквы номера каюты - Пропуски в новом признаке заполнены значением 'Unknown' - Получено 9 уникальных значений: Unknown (687), C (59), B (47), D (33), E (32), A (15), F (13), G (4), T (1) - Исходный столбец Cabin удалён

    Вывод: Все пропуски в данных успешно обработаны. Количество столбцов после обработки — 13.

    Вывод по работе с типами данных:

    В ходе работы с типами данных были выполнены следующие преобразования:

    Преобразование Pclass: - Числовые значения (1, 2, 3) заменены на буквенные коды: F (First class), S (Second class), T (Third class) - Распределение: T — 491 (55.1%), F — 216 (24.2%), S — 184 (20.7%)

    Создание признака Title: - Из столбца Name извлечены титулы с помощью регулярного выражения - Первоначально выделено 17 уникальных титулов - Редкие титулы объединены в категорию 'Other' - Итоговое распределение: Mr — 517 (58.0%), Miss — 182 (20.4%), Mrs — 125 (14.0%), Master — 40 (4.5%), Other — 27 (3.0%) - Признак преобразован в категориальный тип для экономии памяти

    Преобразование Sex: - Значения заменены на числовой формат: male → 0, female → 1 - Распределение: 0 (мужчины) — 577 (64.8%), 1 (женщины) — 314 (35.2%)

    Создание признака FamilySize: - Признак рассчитан по формуле: FamilySize = SibSp + Parch + 1 - Средний размер семьи — 1.90 человека, медиана — 1.00 - Максимальный размер семьи — 11 человек - Большинство пассажиров (537 человек, 60.3%) путешествовали в одиночку

    Создание признака IsAlone: - Бинарный признак: 1 — если FamilySize = 1 (одинокий), 0 — если с семьёй - Распределение: одинокие — 537 (60.3%), с семьёй — 354 (39.7%)

    Итог: Все преобразования типов данных выполнены успешно. Созданы новые информативные признаки: Title, FamilySize, IsAlone.
