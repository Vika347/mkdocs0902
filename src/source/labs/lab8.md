# Лабораторная работа №8
## Скрапинг

### Цель:
Освоение методов скрапинга данных из веб-страниц.

---
### Выполненение работы:
[Ссылка на выполненный ноутбук Google Colab](https://colab.research.google.com/drive/19pjuow4RcbrQauo_NAxYskfANKY2v0CT?usp=sharing)

Был разработан парсер новостного портала ИТМО на Python с использованием библиотек Requests и BeautifulSoup. Реализован автоматический сбор данных о новостях: идентификатор, заголовок, дата публикации, количество просмотров, текст статьи, теги и ссылка на источник.

Собранные данные сохранены в формате CSV для последующего анализа. В ходе работы освоены методы веб-скрапинга, обработки HTML-документов и организации данных для аналитических задач.
