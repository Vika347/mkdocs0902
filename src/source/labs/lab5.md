**Вывод по части 1:** Удаление незначимых признаков улучшило RMSE Random Forest на 1.3%, но незначительно ухудшило линейную регрессию. Random Forest оказался менее чувствительным к "шумовым" признакам.


#### 2. Результаты настройки параметров Random Forest

**Лучшие найденные параметры:**
- `n_estimators`: 200 (количество деревьев)
- `max_depth`: 20 (максимальная глубина)
- `min_samples_split`: 2 (мин. объектов для разбиения)
- `min_samples_leaf`: 1 (мин. объектов в листе)

**Вывод по части 2:** Настройка гиперпараметров не привела к улучшению качества модели. Настроенная модель показала RMSE = 135 730, что на 0.3% хуже базовой. Это может быть связано с:
- Модель подстроилась под конкретные разбиения данных
- Базовой моделью, уже близкой к оптимальной для данного набора данных
- Параметрами `min_samples_leaf=1` и `min_samples_split=2`, делающими деревья слишком глубокими

#### 4. Интеграция модели с веб-сервисом (FastAPI)

**Алгоритм:**
1. Сохранить модель: `joblib.dump(model, 'model.pkl')`
2. Установить: `pip install fastapi uvicorn joblib`
3. Создать `app.py` с FastAPI и эндпоинтом `/predict`
4. Запустить: `uvicorn app:app --port 8000`
5. Тестировать: `curl -X POST http://localhost:8000/predict -d '{...}'`
